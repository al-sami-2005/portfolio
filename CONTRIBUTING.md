# Contributing to Al Sami's Portfolio

Thank you for your interest in this project! 🙌

Since this is a **proprietary project**, contributions work a little differently than in traditional open-source repositories. Please read this guide carefully before contributing.

---

## ⚠️ Important: Source Code is Not Public

The source code of this project is **not publicly licensed**. This means:

- You **cannot** submit code changes (pull requests for source code will not be accepted)
- You **can** contribute to documentation, bug reports, and feature ideas
- If you want access to the source code, see [Requesting Source Code Access](#requesting-source-code-access)

---

## ✅ How You CAN Contribute

### 1. 🐛 Report a Bug in the Live Demo

Found something broken or visually off on the [live demo](https://al-sami-2005.github.io/portfolio/)? Please open a bug report!

**Before reporting:**
- Check that the bug is not already [reported](https://github.com/al-sami-2005/portfolio/issues)
- Test in multiple browsers if possible
- Include your browser, OS, and screen size

[→ Open a Bug Report](https://github.com/al-sami-2005/portfolio/issues/new?template=bug_report.md)

---

### 2. 💡 Suggest a Feature or Improvement

Have an idea that would make this portfolio even better? I'd love to hear it.

[→ Submit a Feature Request](https://github.com/al-sami-2005/portfolio/issues/new?template=feature_request.md)

---

### 3. 📖 Improve Documentation

Found a typo in the README? Spotted outdated information? Feel free to open a PR for documentation-only changes.

**Accepted documentation PRs:**
- README.md improvements
- CONTRIBUTING.md clarifications
- Fixing broken links or typos

---

### 4. ⭐ Star the Repository

The simplest contribution — star this repo to help others discover it!

---

## 🔑 Requesting Source Code Access

If you'd like access to the source code for educational, personal, or commercial purposes:

1. **Email** [alsami1070@gmail.com](mailto:alsami1070@gmail.com?subject=[Source Code Request] Portfolio)
2. **Subject line:** `[Source Code Request] Portfolio`
3. **Include in your message:**
   - Your name and background
   - Your intended use case (education, personal project, commercial, etc.)
   - Any relevant links (GitHub profile, LinkedIn, website)

All requests are reviewed personally. I aim to respond within 48 hours.

When opening an issue, please use the appropriate template:

| 📬 Source Code Request | Requesting access to the source |
